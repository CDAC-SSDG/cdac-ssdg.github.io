# C-DAC Bangalore · System Software Products

A product showcase for the System Software Development Group (SSDG), C-DAC Bangalore.
It is a static website: one `index.html` and an `assets/` folder of brochure images. It needs no build step or server code.

Products: ParaS Compiler, CLAP, Torch-ParaS, PINAKAA Studio, ParaDE, C-HAP, SuParikshan.

Each product has its own link, which you can use for a product-specific QR code:
`#paras-compiler`, `#clap`, `#torch-paras`, `#pinakaa-studio`, `#parade`, `#c-hap`, `#suparikshan`

## Add or update a product
1. Put the brochure PDF in `assets/pdf/` as `Name_Brochure.pdf`, and the brochure image in `assets/` twice: `name.jpg` (about 1400 px wide) and `name_t.jpg` (about 480 px wide, used for the thumbnail).
2. In `index.html`, add or edit an entry in the `P` list. Each entry has: id, family (`paras` or `pin`), image name, name, tagline, summary, key facts, highlights, PDF file name and size, GitHub link and email.
